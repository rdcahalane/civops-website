Working Tools

Hackathon Kaizen Readiness Screen

Score 1–5 on each dimension. A score below 3 on a ★ critical dimension normally requires roadmapping or prerequisite work, regardless of the total.

Challenge Selection Matrix

Enter up to six candidate use cases. Weighted total and rank recalculate live as scores change.

Decision and Gate Log

One line per material decision, assumption, scope change, or gate disposition.

Exception and Failure Test Log

Preserve evidence from failed, degraded, and misleading paths — not only the successful demonstration.

Operational Validation Scorecard

Tie baseline, target, and actual to named evidence sources. Keep observed results separate from inference.

Replication and Reuse Register

Separate reusable assets from platform-, site-, asset-, and customer-specific assumptions.

Focused Event Run Sheet
