Overview / CESMII survey results

CESMII maturity survey — live results, not a mockup

Every chart below is computed from real submitted responses in the running assessment platform — not sample data. The survey follows CESMII's own Smart Manufacturing maturity model: the same Base Questions (firmographic + role) and Assessment (35-question, 6-area maturity instrument) structure CESMII uses in its own Readiness/Roadmap tool.

Sample size — read this first. 3 of 23 invited stakeholders have completed the survey so far (17 more opened it and were nudged on 2026-07-26 — see Next Steps). Every chart on this page recomputes automatically as more responses land; three respondents is enough to prove the analytics pipeline works end to end, not enough yet to call the results representative of the plant.
What's being measured

Six Smart Manufacturing areas, 35 questions, one instrument

Respondents answer maturity questions grouped into the same six areas CESMII's own roadmap tool uses. Each answer maps to a 1–5 maturity level (Reactive → Aware → Collaborative → Proactive → Adaptive). Base Questions (company, role, industry, headcount) drive the function/role pivot further down this page.

The maturity grid

Where each function lands, area by area

Same visual model as CESMII's own roadmap tool: five maturity stages across, six Smart Manufacturing areas down. Each marker is one response's maturity level for that area, shown by department/function — not by individual, to keep respondents anonymous even at low sample sizes. The orange line traces the average across all respondents. The gray bar behind the markers spans the full range — the wider the bar, the more the org disagrees with itself on that area.

What this proves

A real analytics pipeline, not a mockup

  • Every number on this page traces back to a real submitted response in the assessment platform — the same instrument, the same 6 areas, the same maturity scale CESMII uses.
  • The grid, deviation table, and role pivot all recompute from source data — there is nothing hardcoded to update by hand as responses come in.
  • 19 more invited stakeholders have opened the survey and were nudged 2026-07-26 — each additional completion sharpens every chart on this page automatically.

What sharper data enables next

  • True role-silo pivots (Maintenance vs. Engineering vs. IS) once each group clears 3+ responses.
  • A current-state → future-state comparison, the same way CESMII's own roadmap tool tracks progress after a Focus/Roadmap workshop.
  • Feeds directly into the Phase 2 interop kaizen agenda — the widest-deviation areas are the highest-value discussion topics for that room.
